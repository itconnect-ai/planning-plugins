# vibe — 비개발자용 5단계 바이브코딩 파이프라인

아이디어에서 시작해 PRD → 디자인 기준과 시안 → FRD → TRD → 개발 계획까지 AI와의 대화로 완성하고, STORY 단위로 개발을 진행하는 Claude Code 플러그인입니다. 모든 결정은 A/B/C/D 선택형 + 한 줄 미니 강의로 진행되어, 선택지를 읽는 것만으로 개념을 학습하게 됩니다.

## 사용 순서

프로젝트 폴더에서 `claude`를 실행한 뒤, 아래 명령을 순서대로 입력합니다.

| 순서 | 명령 | 하는 일 | 라운드 방식 | 산출물 |
|---|---|---|---|---|
| 1 | `/vibe:01-prd` | 아이디어 구체화 + PRD 작성 (첫 실행 시 대화 방식(간단/꼼꼼) 설정 포함) | 꼼꼼 가변 / 간단 기본 2 | `docs/prd.md`, `docs/setup.md` |
| 2 | `/vibe:02-design` | 디자인 기준 작성과 가능한 경우 시안 제작·검토 | 꼼꼼 가변 / 간단 기본 2 | `docs/design-prompt.md`, 화면 시안(선택) |
| 3 | `/vibe:03-frd` | 시안 대조 → 기능 분해(CRUD·숨은 기능) → 정책 결정 | 꼼꼼 가변 / 간단 기본 2 | `docs/frd.md` |
| 4 | `/vibe:04-trd` | 기술 스택·구조 결정, TRD 작성 | 꼼꼼 가변 / 간단 기본 2 | `docs/trd.md` |
| 5 | `/vibe:05-plan` | EPIC/STORY 개발 계획 수립 | 꼼꼼 가변 / 간단 기본 2 | `docs/plan.md` |
| 반복 | `/vibe:build` | 다음 STORY 1개 구현 + 확인 후 체크 | — | 코드 + plan.md 갱신 |
| 수시 | `/vibe:status` | 진행 현황과 다음 명령 확인 | — | — |
| 도움말 | `/vibe:help` | 명령 목록과 진행 순서 안내 (처음 시작할 때) | — | — |

- 2단계는 사용 가능한 도구가 있으면 AI가 화면 시안을 직접 만들거나 기존 HTML·이미지를 확인합니다. 도구가 없으면 `docs/design-prompt.md`를 Claude Design 또는 Google Stitch에서 사용하도록 안내합니다. 새로운 화면·기능·정책은 사용자 승인 없이 추가하지 않으며, 시안 이미지는 권장이지만 **선택 산출물**입니다.
- 다른 이름과 충돌이 없으면 접두어 없이 `/01-prd` 처럼 짧게 입력해도 동작합니다.

## 수업 시간 배분 가이드 (참고)

아래는 수업에서 다룰 분량을 잡기 위한 예시일 뿐 완료 시간 기준이 아닙니다. 단계를 수업 안에 끝내지 않아도 됩니다 — 각 스킬이 `상태: 작성 중`으로 저장해 두므로 다음 시간에 이어서 진행할 수 있습니다. 꼼꼼 모드는 완성도에 따라 보완 라운드를 추가하고, 간단 모드도 핵심 결정이 부족하면 기본 2라운드를 넘어 이어집니다.

| 단계 | 수업 분량 예시 |
|---|---|
| 1단계 PRD | 20~30분 |
| 2단계 시안 (제작 포함) | 15~20분 |
| 3단계 FRD | 20~30분 |
| 4단계 TRD | 15~20분 |
| 5단계 계획 | 10분 |
| build (STORY 1개당) | 10~30분 |

## 수업 운영 팁

- **설치·업데이트 직후에는 반드시 재시작**: 플러그인을 설치하거나 업데이트한 뒤 Claude Code를 껐다 켜지 않으면 `/vibe:...` 명령이 목록에 나타나지 않습니다. 수업 초반 "명령이 안 보여요"의 대부분이 이 경우입니다. 재시작 후 `/vibe:help`로 명령 목록을 확인시키세요.
- **대화 방식 선택**: `/vibe:01-prd` 첫 실행 시 "간단"을 고르면 기본 2라운드로 핵심 결정만 묻고 나머지는 추천·추정으로 채웁니다. "꼼꼼"은 AI가 누락·모호·충돌 항목을 단계별로 점검해 필요한 만큼 보완 라운드를 이어갑니다. 범위 조정은 STORY 개수가 아니라 FRD의 필수/부가 분류(MVP 조정)로 이루어지므로, 필수로 확정된 기능은 모드와 무관하게 전부 구현됩니다. 모드는 `docs/setup.md`의 "진행 모드" 줄을 고치거나 대화 중에 요청해 바꿀 수 있습니다.
- **완료 기준은 로컬 실행**: 계획의 필수 범위는 localhost에서 돌아가는 것까지이고, 배포(Git·Vercel·Supabase 연동)는 마지막 "배포(선택)" EPIC으로 분리되어 있습니다. 배포 계정 가입은 강의에서 강사와 함께 진행하면 됩니다.
- **권한 프롬프트 줄이기**: 세션 시작 후 Shift+Tab으로 `acceptEdits` 모드를 켜면 문서 저장 때마다 승인을 묻지 않습니다. 시작 템플릿 저장소를 쓰는 경우 `.claude/settings.json`에 허용 규칙을 넣어두는 방법도 있습니다.
- **진도가 밀린 학습자**: `/vibe:status`로 현재 위치를 확인시키고, 각 단계 스킬이 이전 산출물 유무를 스스로 검사하므로 중간부터 다시 시작해도 안전합니다.
- **산출물 경로는 고정**: 문서는 `docs/`, 시안은 `design/`에만 저장됩니다. 폴더를 옮기지 마세요.
- **데이터 정책**: 회사 업무 주제는 실제 회사 데이터·고객 정보 대신 가짜 데이터로 개발하도록 1단계에서 자동으로 원칙이 잡힙니다. 공개 데이터(주식 시세 등)를 쓰는 재미 주제는 예외입니다.
