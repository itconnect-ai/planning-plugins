# vibe — 비개발자용 5단계 바이브코딩 파이프라인

아이디어에서 시작해 PRD → 디자인 프롬프트 → FRD → TRD → 개발 계획까지 AI와의 대화로 완성하고, STORY 단위로 개발을 진행하는 Claude Code 플러그인입니다. 모든 결정은 A/B/C/D 선택형 + 한 줄 미니 강의로 진행되어, 선택지를 읽는 것만으로 개념을 학습하게 됩니다.

## 사용 순서

프로젝트 폴더에서 `claude`를 실행한 뒤, 아래 명령을 순서대로 입력합니다.

| 순서 | 명령 | 하는 일 | 대화 라운드 | 산출물 |
|---|---|---|---|---|
| 1 | `/vibe:01-prd` | 아이디어 구체화 + PRD 작성 | 3~4 | `docs/prd.md` |
| 2 | `/vibe:02-design` | 디자인 시안 생성용 프롬프트 작성 | 1 | `docs/design-prompt.md` |
| — | (수동) | 프롬프트로 시안 제작 후 저장 | — | `design/01-home.png` 등 |
| 3 | `/vibe:03-frd` | 시안 대조 → 기능 분해(CRUD·숨은 기능) → 정책 결정 | 3 | `docs/frd.md` |
| 4 | `/vibe:04-trd` | 기술 스택·구조 결정, TRD 작성 | 2~3 | `docs/trd.md` |
| 5 | `/vibe:05-plan` | EPIC/STORY 개발 계획 수립 | 1~2 | `docs/plan.md` |
| 반복 | `/vibe:build` | 다음 STORY 1개 구현 + 확인 후 체크 | — | 코드 + plan.md 갱신 |
| 수시 | `/vibe:status` | 진행 현황과 다음 명령 확인 | — | — |

- 2단계 시안 제작은 플러그인 밖에서 합니다. Claude 유료 사용자는 Claude Design, 그 외에는 Google Stitch(stitch.withgoogle.com)에 `docs/design-prompt.md`의 블록을 붙여넣어 만든 뒤, 이미지를 `design/` 폴더에 저장합니다.
- 다른 이름과 충돌이 없으면 접두어 없이 `/01-prd` 처럼 짧게 입력해도 동작합니다.

## 수업 시간 배분 가이드 (참고)

| 단계 | 권장 시간 |
|---|---|
| 1단계 PRD | 20~30분 |
| 2단계 시안 (제작 포함) | 15~20분 |
| 3단계 FRD | 20~30분 |
| 4단계 TRD | 15~20분 |
| 5단계 계획 | 10분 |
| build (STORY 1개당) | 10~30분 |

## 수업 운영 팁

- **권한 프롬프트 줄이기**: 세션 시작 후 Shift+Tab으로 `acceptEdits` 모드를 켜면 문서 저장 때마다 승인을 묻지 않습니다. 시작 템플릿 저장소를 쓰는 경우 `.claude/settings.json`에 허용 규칙을 넣어두는 방법도 있습니다.
- **진도가 밀린 학습자**: `/vibe:status`로 현재 위치를 확인시키고, 각 단계 스킬이 이전 산출물 유무를 스스로 검사하므로 중간부터 다시 시작해도 안전합니다.
- **산출물 경로는 고정**: 문서는 `docs/`, 시안은 `design/`에만 저장됩니다. 폴더를 옮기지 마세요.
